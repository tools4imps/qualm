# qualm

qualm fails a pull request when an experienced reviewer would ask for the change to be simplified, and tells the coding agent what to fix. It asks TypeSafe's Jev, a System One decision model, about each changed file's diff.

It's the subjective sibling of [exhale](https://github.com/tools4imps/exhale-ruby) in the tools for [Impatient Programming](https://impatientprogramming.org).

The first version is being built. The design is in `docs/superpowers/specs/`.
